TV Game Show Simulation
This project simulates a competition similar to TV game shows where contestants are judged by their coaches and the audience. Each contestant is accompanied by a coach, and both coaches and the audience assign points to the contestants.

Project Description
The program allows for:

A set number of contestants (at least 5) and weeks (at least 3) to be entered by the user.
Weekly scoring, where each coach assigns points (1, 2, 3) to 3 contestants, and similarly, the audience assigns points to 3 contestants as well.
The total score for each contestant for a week is calculated by summing the points given by the coaches and audience. The audience's points are weighted based on the number of coaches.
At the end of each week, the rankings are displayed in descending order based on the total score, with tie-breakers based on the coaches' scores and contestant numbers.
Features
Input for number of contestants and weeks.
Weekly score assignments for both coaches and the audience.
Weekly rankings sorted by total score, coach's score, and contestant number.
Installation
To run the project locally:

Clone the repository
First, copy the repository to your local machine by running the following command:
git clone <repository_url>
Open the project
After cloning the repository, open the project in your preferred Integrated Development Environment (IDE) or text editor.
Run the program

You can now run the program either from the command line or directly within your IDE. Follow the prompts in the console to enter data and see the results.

Usage
The program will prompt you for:
The number of contestants and weeks.
For each week, input contestant numbers and corresponding points from coaches and the audience.
